# Chatterbox screenshot pack, round 2 (UX/UI review)

## About the app

Chatterbox is a personal Mac + iPhone app for running and supervising many Claude and Codex
coding and design agent sessions at once. The Mac runs the agents; the phone is a remote for them.
Key concepts: **sessions** (also called chats or threads: one conversation with one agent);
**projects** and **Studios**, the places work lives (a project is a code folder, a Studio is a
creative workspace such as "USA Archery" holding several sessions; a session can also stand alone
under Chats); the **Desk**, a board of five columns, left to right: **To do** (requests waiting to
be placed and started), **Working** (sessions mid-reply), **Needs you** (approvals, plans and
questions), **Ready to mark complete** (sessions that finished and ask nothing) and **Done**
(marked complete this week); **automations**, scheduled routines that run a session on the Mac;
and **approvals**, where an agent asks before running a command.

All content is fixture data from the test harnesses (no real chats). Captured November 4, 2026.
Dark mode unless noted. Same harnesses as round 1 (screens/INDEX.md); numbers 01–28 are the same
screens as round 1 where they still exist, and 29–34 are new. Since round 1 the Desk became the
board described above, and the panel's agreed fixes were applied (one approval card everywhere,
contrast, naming, New Chat permissions, offline state, safer Silence, tab bar clearance, Mac
primary buttons, Mac selection vs needs-you, the Command Center fixture).
