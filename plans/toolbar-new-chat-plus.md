# Standalone new-chat plus

Shelby requested a plus outside the three view buttons. Place a native New Chat button immediately after the segmented views group, before flexible space, visible in every view. One click opens a regular new chat using existing defaults/reuse behavior. No menu and no changes to the three view shortcuts.

Linear scoped implementation in this session. Verify Mac build and existing toolbar regression, install under standing authorization. Rollback with previous Core pin. No daemon restart required.
